# Haven — AI Mental Health Companion

Haven is an AI-powered conversational assistant designed to provide
emotional support to university students using LLM-based inference.

## Features
- Emotion-aware conversational responses
- Session-based context handling
- Light and Dark mode UI
- Grounding and emergency support prompts

## Tech Stack
- Streamlit
- Groq LLM API
- LangChain

## Disclaimer
This application does not replace professional mental health care.
